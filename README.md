# 🧠 TaskMind AI

TaskMind AI is a state-of-the-art, AI-assisted task management and productivity workspace built with **FastAPI**, **PostgreSQL (with pgvector)**, and **Streamlit**. It harnesses LLM orchestration (via Ollama, Groq, or OpenAI) to analyze task lists, automatically schedule reminders, and generate structured daily plans using RAG (Retrieval-Augmented Generation).

---

## 🏗️ System Architecture

TaskMind AI uses a decoupled three-tier architecture:

```text
       ┌────────────────────────┐
       │   Streamlit Frontend   │  (Port 8501)
       └───────────┬────────────┘
                   │  HTTP REST / WebSockets
                   ▼
       ┌────────────────────────┐      ┌────────────────────────┐
       │    FastAPI Backend     ├─────►│  Ollama / Groq / OpenAI│  (AI Planning & Embeddings)
       └───────────┬────────────┘      └────────────────────────┘
                   │  SQL Queries / Vector Ops
                   ▼
       ┌────────────────────────┐
       │  Postgres + pgvector   │  (Port 5432 - Tasks, Users, Embeddings)
       └────────────────────────┘
```

- **Frontend**: Streamlit-based interactive dashboard styled with a high-end glassmorphic theme.
- **Backend**: FastAPI web service exposing REST APIs, handling user registration/login (JWT Auth), and scheduling reminder tasks.
- **Database**: PostgreSQL with the `pgvector` extension for semantic task indexing and RAG-based search.

---

## ✨ Key Features

- 🔐 **Secure JWT Authentication**: Register, sign in, and manage private user-specific task dashboards.
- 📅 **Intelligent Scheduling & Calendar**: Capture tasks with dynamic dates, prioritize, and view daily task schedules.
- ⚡ **AI Task Extraction & Auto-Prioritization**: Parse dates and priority numbers automatically from natural language input.
- 🧠 **Contextual RAG Chat**: Chat with an AI assistant that queries your task list to help you summarize, prioritize, or answer questions about your workload.
- 📋 **Automated Daily Planner**: Summarize upcoming deadlines and get a structured hourly schedule generated by LLMs.
- 🔔 **Telegram Notifications**: Integrate with a Telegram Bot to receive background reminders for upcoming tasks.

## 🛠️ Local Development

### Prerequisites
- Docker & Docker Compose
- Groq or OpenAI API Key (or local Ollama installation)

### Steps

1. **Clone the repository and go to the directory**:
   ```bash
   git clone <your-repository-url> taskmind-ai
   cd taskmind-ai
   ```

2. **Set up your environment configuration**:
   ```bash
   cp .env.example .env
   ```
   Open `.env` and fill in your details (e.g., `GROQ_API_KEY`, `OPENAI_API_KEY`).

3. **Spin up the stack**:
   ```bash
   docker compose up --build
   ```

4. **Access the applications**:
   - 🌐 **Streamlit UI**: [http://localhost:8501](http://localhost:8501)
   - 🔌 **FastAPI Docs**: [http://localhost:8001/docs](http://localhost:8001/docs) *(Mapped to port 8001 on the host)*

## 🔒 Security & Best Practices

- Always ensure your `SECRET_KEY` is a strong random secret in production.
- Keep the `api` and `pgvector_db` service ports blocked from public inbound access on your cloud provider (e.g., via security groups). Only Streamlit (`8501`) needs external access.
- Avoid committing `.env` or `.env.backup` files to your version control repository (they are gitignored by default).
